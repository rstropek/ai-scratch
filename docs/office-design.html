The office in Scratch's world, at adult density

The office uses the kids' app's own visual language: Scratch 3's GUI palette, Helvetica Neue and the purple menu bar. Teachers recognise the product they hand to their class. The work area is calm: white panels on Scratch's light-blue ground, tables instead of cards, purple only where something can be clicked or has focus.

  • Same palette as the kids' app, defined once in the office. The tokens live only in apps/office/app/globals.css (Tailwind's own palette and type scale are switched off); components in apps/office/components/ui. No slate, no Tailwind greys.
  • Adult density. 15 px body, 40 px fields (the kids' 48 px fields are for the dialog kids meet), 14 px tables. Nothing bounces, no hearts.
  • Colour does jobs. Purple: navigation, actions, focus. Blue: information and time ("Geplant"). Green: running, done. Yellow: attention. Scratch's orange: errors and destructive actions. A state always has a word or an icon too.
  • The code is the hero. An access code always appears the way kids will type it: bold, spaced, lilac, with a copy button. After creating one, the teacher gets a hand-over card big enough to project.
  • No toasts, few dialogs. After an action, a banner on the next page says what happened and stays. A dialog only guards something destructive, built like Scratch's own (and the Locker dialog).

Shape and focus

  • Fields: 40 px high, radius 5 px, border hsla(0,0%,0%,.15); focus is a purple border plus Scratch's 4 px lilac halo (--ring), as in the Locker dialog.
  • Buttons: radius 4 px, bold 14 px. Panels: radius 8 px, a 1 px blue-grey edge, no shadow. Only specimens on this page get a shadow.
  • Digits in tables, money and codes: tabular-nums. Money as 1,20 €, dates as Fr 31.10.2026, times as 08:00–09:40 (Vienna time).
  • Icons: lucide, 16 px, 2 px stroke, the set the kids' app already ships.

  • Status is about time (Geplant, Läuft bis …, Abgelaufen); money lives in its own column. A code that is in its window but out of budget shows the orange chip "Gestoppt: Budget aufgebraucht".
  • Meter colours follow the kids' Gedächtnis gauge: blue, yellow from 80 %, orange at 100 %.
  • Row actions sit in one menu; the copy button stays next to the code, because copying is the most frequent action. "Löschen …" opens the confirmation dialog (see Feedback).

  • Sorting and filtering are links with query parameters (?status=aktiv&sort=zeit), server-rendered: the page works without client JavaScript and survives a reload.

Abbrechen
  • The server validates (it must anyway); the client adds only the native required, maxlength and the live counter. After a failed submit the page keeps every value.
  • An error says what is wrong and what to do, in "Sie", and names the value ("Von 08:00 bis 12:30 …"). Errors appear on submit, then clear per field as soon as the input is valid.
  • The default of the "frage KI" switch is still open in the platform plan; the form shows "on" only as an example.

    Zustimmung

    Sicherheitsprüfung bestandenCloudflare Turnstile, ohne Tracking-Cookies
    Alle Felder ohne „optional“ sind nötig.
    • Groups instead of a wizard: the form is short enough for one page, and a teacher can see everything that's asked before starting.
    • The Turnstile widget is drawn here as a stand-in. The real one renders Cloudflare's own box in managed mode; most visitors never click it.
    • The Schulkennzahl is a suggestion (not in the plan yet): Austrian schools have a six-digit number that makes checking an application quick.
    • "Sent" leads to "confirm your email", not to "done", because the plan only notifies Rainer after the confirmation.

    Feedback: banners and the one dialog

    Banners sit at the top of the page content, under the title bar, in the order they happened. Success and info can be closed; warnings and errors stay until the cause is gone.

    Controls and their states

    Native elements styled with the tokens: no custom selects, no date-picker library. Every control has hover, focus, disabled and, where it takes input, an invalid state.

    Buttons

    • One primary button per form or page header. While a request runs, the button keeps its width, shows a spinner and the verb in progress.
    • A disabled submit is rare: prefer letting people submit and then naming what's missing.

    Text fields

    Diese E-Mail-Adresse ist unvollständig. Beispiel: name@schule.at

    Choices

    Ohne Zustimmung können wir den Antrag nicht annehmen.

    Writing rules for texts

    • "Sie" for teachers, short sentences, no exclamation marks, no "Ups".
    • Buttons name the action: "Code erstellen", "Antrag senden", "Code löschen". Never "OK" or "Absenden".
    • Errors: what is wrong, then what to do. With the value when it helps ("Von 08:00 bis 12:30 sind 4 h 30 min").
    • Every text in lib/texts.ts, as today; errors there too, keyed by field and reason.
